# LX-2BUPS-Case Remix

This model is an improvment to the original model [here](https://www.printables.com/model/906875-18650-router-onu-ups-case)

You can find it on [Printables](https://www.printables.com/model/1324312-lx-2bups-case-with-mounting-holes)

It adds wall mounting options by adding mounts to the lid and base,
also I added a double UPS alternative which holds two LX-2BUPS in a single case.

For perfect fitting I recommend printing with 1% extra scale to easen the tolerances.
