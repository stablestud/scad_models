# ZS-0004 EMI Filter Case

This case adds an additional layer of protection to ZS-0004.

I was not satisfied with the filters casing, so I created this one to add additionally more protection.
For the user its now less dangerous as the mains power is now completey covered up.

It is only compatible to the ZS-0004 which already has a metal/plastic casing, bare PCB is not compatible

It has enough room for proper cable management (stress relief) and has room for additional EMI filtering components.
I for example added on each side of the EMI X2 2.2uF 275VAC capacitors to even filter out more noise

The model can be found also [here](https://www.thingiverse.com/thing:6932816)
