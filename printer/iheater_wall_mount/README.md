# iHeater Wall Mount

This model adds a wall mount for the iHeater 200W r1.    
I have created it, as using double sided tape did not work reliably for me, during print the iHeater fell multiple times off the wall.

Using this mount you can slot the iHeater inside it.
It will be more securely attached as the mount can be screwed to the wall with four countersunk M4 screws

Two variants exist:
* `width_mount` - holds the iHeater by holding its width
* `length_mount` - holds the iHeater by holding its length
