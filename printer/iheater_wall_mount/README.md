# iHeater Wall Mount

This model adds a wall mount for the iHeater 200W r1
I have created it as using double sided tape did not work reliably for me,
mid printing it fell off my wall multiple times.

Using this mount you can slot the iHeater inside it and it will be more securely attached to the wall,
as the mount can be screwed onto the wall

Two variants exist:
* width_mount - holds the iHeater by holding its width
* length_mount - holds the iHeater by holding its length
